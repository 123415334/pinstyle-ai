# Release Assets

Store-submission media is grouped by product surface and readiness:

- `store-screenshots/chrome/final/`: approved Chrome/Edge listing screenshots referenced by `documentation/CHROME_STORE_LISTING.md`.
- `store-screenshots/chrome/drafts/`: retained browser-listing working exports.
- `store-screenshots/desktop/final/`: final desktop product and promotional images.
- `store-screenshots/desktop/drafts/`: retained desktop working exports.

Promote a draft by copying it into the appropriate `final/` folder with a descriptive stable filename and updating the relevant store metadata document.
